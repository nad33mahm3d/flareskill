# Skill template

Copy [`SKILL.md`](./SKILL.md) into `skills/<category>/<name>/`, or run:

```bash
npx flareskill create my-skill-name
```

Then:

1. Edit frontmatter and sections.
2. `npx flareskill validate ./skills/<category>/<name>`
3. `npm run registry:build` (maintainers)
4. Open a pull request

See [CONTRIBUTING.md](../../CONTRIBUTING.md) and [creating-skills.md](../creating-skills.md).
